Find, inspect and chat with every local AI model.

Arqade scans your drives for GGUF, SafeTensors, PyTorch, TensorFlow, ONNX and Ollama models, then lets you chat with them under a custom system prompt and a real prompt authority hierarchy.

🔍 Model scanner

Quick, home-folder or whole-drive scans. Understands Hugging Face caches, Ollama, LM Studio, sharded weights and TF SavedModels. Read-only — pickle files are listed, never loaded.

🧠 PyTorch + TensorFlow + more

Transformers, JAX, ONNX Runtime, llama.cpp, scikit-learn, XGBoost, LangChain, LlamaIndex and ~70 more, installed per-package so one failure never blocks the rest.

🛡 Prompt authority hierarchy

Stack Root → Developer → Operator → User layers. Lock layers, mark content as untrusted data, pick a conflict policy, and see the compiled prompt live.

🌗 Dark first, extension-aware

Dark by default, light on request. If Dark Reader, Night Eye & friends are active, Arqade switches to its light base so they don't double-invert.
